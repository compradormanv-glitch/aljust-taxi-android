# Al.just Táxi — APK Android

Este projeto cria um APK Android que abre o aplicativo Al.just Táxi em uma janela nativa.

O APK é gerado automaticamente pelo GitHub Actions sempre que houver um push para `main`.

## Como usar

1. Crie um repositório separado, por exemplo `aljust-taxi-android`.
2. Envie todos os ficheiros deste projeto para a raiz do repositório.
3. Faça Commit.
4. Abra a aba **Actions** e aguarde o workflow `Build Al.just Táxi APK`.
5. Quando terminar, haverá um Release com o APK.
6. O APK pode ser baixado no telefone Android.

A versão produzida é de teste (debug). Antes da Google Play Store, deve ser criada uma versão release assinada.
